# Limitations and Legal Verification

- This tool is guidance-only and not legal advice.
- State and municipal licensing logic is partially modeled for MVP scope.
- Thresholds and compliance rules can change; always verify with official portals.
- API integrations depend on provider availability and account permissions.
- Google Sheets and email actions require valid credentials and network access.
- For production, use secret managers and hardened infra controls (not plain env files).
